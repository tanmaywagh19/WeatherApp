# 🌤️ Weather App – React.js

A simple and responsive **Weather Application built with React.js** as a practice project to understand React fundamentals and working with external APIs.

The application uses the **OpenWeatherMap API** to fetch and display real-time weather information for a searched city.

## 🚀 Features

* 🔍 Search weather by city name
* 🌡️ Display current temperature
* 🌥️ Display weather conditions
* 💧 Display humidity
* 💨 Display wind speed
* 🌍 Display city and country information
* ⚡ Fetch real-time weather data from an external API
* 📱 Responsive design

## 🛠️ Technologies Used

* **React.js** – Frontend library
* **JavaScript (ES6+)** – Application logic
* **CSS** – Styling
* **OpenWeatherMap API** – Weather data
* **Vite** – React development environment

## 🧠 React Concepts Practiced

This project was mainly built to practice React.js concepts, including:

* Functional Components
* JSX
* Props
* `useState()` Hook
* Event Handling
* Conditional Rendering
* API Requests using `fetch()`
* Handling asynchronous data
* Component-based UI development

## 🔗 API

Weather data is fetched from:

**OpenWeatherMap API**

API endpoint used:

```text
https://api.openweathermap.org/data/2.5/weather
```
